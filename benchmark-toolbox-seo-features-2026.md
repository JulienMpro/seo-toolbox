# Inventaire des FEATURES — Outils SEO spécialisés payants + outils gratuits sans API

**Objectif** : benchmark concurrentiel pour la construction d'une toolbox consultant SEO reproduisant les features des outils payants via l'API DataForSEO (moins cher) + outils gratuits.
**Règle** : zéro donnée inventée — feature non confirmée par une source = `N/D`.
**Date de collecte** : août 2026 (marché volatil — signaler toute acquisition/pivot constaté).
**Méthode** : visites des sites officiels (curl + navigateur), extraction des pages features/produits.

## Partie B — Outils GRATUITS SANS API (toolbox consultant)

> Format : **outil** — feature principale → ce qu'il apporte.

- **Google Search Console** — données de performance (impressions/clics/position), indexation, couverture, Core Web Vitals, soumission sitemap → la source de vérité Google gratuite pour piloter et diagnostiquer un site.
- **Bing Webmaster Tools** — indexation Bing, recherche de mots-clés, audit SEO, soumission d'URL → visibilité sur Bing/DDG (et donc indirectement ChatGPT qui s'appuie sur Bing).
- **PageSpeed Insights** — score performance + Core Web Vitals (Lighthouse) mobile/desktop → priorisation des corrections de vitesse.
- **Rich Results Test** — validation des données structurées / rich results → vérifier l'éligibilité aux rich snippets avant déploiement.
- **Mobile-Friendly Test** — compatibilité mobile (désormais intégré à GSC/PSI) → détection des problèmes mobile-first.
- **Google Trends** — tendances et saisonnalité des recherches → caler la stratégie éditoriale sur la demande réelle.
- **Google Keyword Planner** — volumes de recherche (via compte Google Ads) → estimation des volumes pour prioriser les mots-clés.
- **Google Business Profile** — fiche établissement + insights locaux → présence locale et signaux de confiance.
- **Ahrefs Webmaster Tools (gratuit)** — audit de site, backlinks, mots-clés de SES propres sites → données Ahrefs limitées mais gratuites sur ses propres propriétés.
- **Bing URL Submission** — soumission d'URLs à l'index Bing → accélérer l'indexation sur Bing.
- **Common Crawl** — dataset open source de crawl du web (index) → analyse backlinks/indexation à grande échelle sans API.
- **Wayback Machine (web.archive.org)** — historique des versions de pages → audit d'évolution d'un site/contenu supprimé, reconstitution.
- **W3C Validator** — validation HTML → détection d'erreurs de balisage.
- **GTmetrix (gratuit)** — performance page + recommandations → diagnostic vitesse.
- **Pingdom (gratuit)** — uptime + performance → disponibilité et temps de réponse.
- **securityheaders.com** — analyse des en-têtes de sécurité HTTP (CSP, HSTS…) → conformité sécurité des en-têtes.
- **copy.sh (v86)** — émulateur x86 dans le navigateur → ⚠️ **pas un outil SEO** (outil d'émulation de VM) ; utile uniquement pour tester des environnements legacy. Pertinence SEO : N/D.

### Compléments gratuits sans API utiles (hors liste, ajoutés)
